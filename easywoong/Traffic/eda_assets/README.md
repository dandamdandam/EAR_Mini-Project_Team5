# TrafficFlowBench EDA 자료

### 이번 실행에서 확인한 규모

- 전체 10개 패널, 본선 링크 1,583개. 패널별 링크 수는 44~352개입니다.
- Train 원본 본선은 124,461,792행, 품질 적격 비율은 76.40%입니다. 마스킹 전에도 flow 결측률은 16.53%입니다.
- 최종 제출은 6,980,503행입니다. 관측 전체 행 수와 제출 대상 행 수는 다릅니다.
- 선택 패널 D7_I10_E의 하루 입력은 (288, 146, 4), Task 2 예제 입력은 (12, 146, 4)이며 미래 출력은 (6, 146)입니다.
- 선택 패널 Task 4는 경로 4,278개에 대해 공개 링크 제약 137개입니다. 제약 수는 행렬 rank의 상한일 뿐 실제 rank를 계산한 값은 아닙니다.

전체 요약은 tables/*.csv, 그림은 figures/*.png에 저장했습니다. 분포 표본·작은 모델 실험의 값은 각 셀에서 명시한 기간과 패널에만 해당합니다.


원본 설명과 재실행 코드: ../eda.ipynb. CSV는 계산 결과, PNG는 발표용 그림입니다.
